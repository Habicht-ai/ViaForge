Dein erster Test
  1. Server starten. Wähle eine Version und klicke auf „Starten“. Sobald sie online ist, kannst du verbinden.
  2. Adresse kopieren. In Minecraft unter Multiplayer → Direkt verbinden einfügen. Wähle dieselbe Version in ViaForge.
  3. Welt erkunden. Der Knopf an der Ankunftsplattform führt zur Navigation: Blöcke, Itemkisten, Mobs und Teststationen.
  4. Gezielt testen. Boote und Wasser, Betten, Schilde sowie Creative-/Survival-Wechsel stehen an den Teststationen bereit. Der Katalog zeigt die Position einzelner Inhalte.
  5. Mit Speichern beenden. „Stoppen“ speichert die Welt. Das Schließen dieser Webseite lässt die Server weiterlaufen.
Starte kleinere Gruppen. Vor jedem Start wird der freie Speicher geprüft.
Moderne Blocktypen werden mit Standardzuständen ausgestellt. Nicht jede Zustands- oder NBT-Variante ist enthalten; Bosse werden auf Knopfdruck erzeugt.

  

  
Anwendung beenden
Du kannst alle vom Testlabor verwalteten Server speichern und beenden oder nur die Webverwaltung schließen. Bereits laufende Aufträge werden zuerst abgeschlossen.
